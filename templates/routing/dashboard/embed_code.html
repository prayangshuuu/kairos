Inline Embed

Displays the routing form directly within your site's content.

<div id="kairos-inline-container"></div>
<script src="https://{{ domain }}/static/js/embed.js"></script>
<script>
    window.KairosWidget.init({
        url: '{{ embed_url }}',
        mode: 'inline',
        parentElement: document.getElementById('kairos-inline-container')
    });
</script>

Popup Embed

Opens the routing form in a modal over your site when a button is clicked.

<button onclick="window.KairosWidget.openPopup()">Book Time</button>
<script src="https://{{ domain }}/static/js/embed.js"></script>
<script>
    window.KairosWidget.init({
        url: '{{ embed_url }}',
        mode: 'popup'
    });
</script>
